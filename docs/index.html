Caratteristiche principali

  • ⚡ Puro Rust + egui: Interfaccia grafica nativa, ultra-leggera e veloce.
  • 🔄 Aggiornamenti automatici: Controlla direttamente le release stabili da GitHub.
  • 🔒 Sicurezza garantita: Streaming download con verifica dell'hash SHA256.
  • 🚀 Avvio automatico: Opzione integrata per l'avvio all'accesso di sistema Linux (XDG Autostart).
  • 📦 Formato AppImage: Nessuna installazione richiesta, basta eseguire l'AppImage.
