# Suppaworld Launcher

Il launcher ufficiale per l'ecosistema **Suppaworld**.

## Funzionalità
- **Gestione Applicazioni:** Scopri, scarica e aggiorna le app Suppaworld.
- **Rilevamento Aggiornamenti:** Controlla automaticamente le nuove release su GitHub.
- **Installazione Sicura:** Download in streaming con verifica hash SHA256.
- **Integrazione di Sistema:** Opzione per l'avvio automatico all'accesso Linux.
- **Interfaccia Nativa:** Scritto in puro Rust con `egui`, senza Electron o webview pesanti.

## Tecnologie
- **Linguaggio:** Rust
- **UI:** `eframe` / `egui`
- **Networking:** `reqwest`
- **Deployment:** AppImage (via `linuxdeploy`)
